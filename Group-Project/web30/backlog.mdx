# FE & BE 분리

## 🎨 Frontend 백로그 (FE)

> React + TypeScript 중심의 GUI, 윈도우 매니저, UI 상태 관리 및 사용자 경험 구현

## 🧱 EPIC 1. 윈도우 매니저 (Window Manager)

> 창 생성, 이동, 포커스, 최소화/닫기 등 UI 중심의 윈도우 시스템 구현

- 여러 개의 윈도우를 동시에 띄울 수 있다.
- 클릭한 창이 최상단으로 올라오며 포커스가 변경된다.
- 각 윈도우에는 제목 표시줄, 최소화, 전체화면, 닫기 버튼이 있다.
- 윈도우를 드래그로 이동할 수 있다.
- 윈도우 상태(z-index, active 상태 등)는 전역 store에서 관리된다.
- 서버의 `/windows/open`, `/windows/move`, `/windows/close` 응답 결과에 맞게 UI를 갱신한다.

## 💬 EPIC 2. 터미널 (Terminal)

> 명령어 입력과 결과 출력 UI, API 연동

- 기본 터미널 윈도우를 자동으로 실행한다.
- 입력창과 출력창을 분리하여 표시한다.
- 사용자는 명령어를 입력하고 엔터로 실행할 수 있다.
- `/syscall` API로 명령을 전달하고 결과를 렌더링한다.
- `clear`, `help`, `date`, `uname`, `echo` 등의 명령 결과를 출력한다.
- 에러 발생 시 에러 메시지를 출력한다.
- 터미널 상태는 전역 상태(store)로 관리된다.

## ⚙️ EPIC 3. 이벤트 처리 및 백엔드 연동

> 마우스, 키보드 이벤트 감지 및 API 통신

- 활성 윈도우의 마우스 이벤트(`onMouseDown`, `onMouseMove`, `onMouseUp`)를 감지한다.
- 활성 윈도우의 키보드 이벤트(`onKeyDown`, `onKeyUp`)를 감지한다.
- 감지된 이벤트를 `/system/gui/` API로 전달한다.
- 서버 응답을 받아 렌더링에 반영한다.
- 응답 지연 발생 시, UI 로딩 상태를 표시한다.

## 🎨 EPIC 4. UI 컴포넌트 시스템

> 재사용 가능한 UI 구조와 전역 스타일 설계

- 버튼, 입력창(1줄/다줄), 레이블 등 공통 컴포넌트를 설계한다.
- 공통 UI는 터미널, 메모장, 제어판 등에서 재사용된다.
- 전역 store를 통한 UI 상태 동기화 구조를 구현한다.
- CSS는 Styled Components 또는 Tailwind로 자유 구성한다.
- 윈도우 이동 및 애니메이션은 GPU 렌더링 최적화 기반으로 구현한다.

## 🗂️ EPIC 5. 파일 탐색기 & 바탕화면

> 파일 시스템과 프로그램 실행 UI

- 바탕화면에 아이콘을 배치할 수 있다.
- 아이콘을 더블클릭하면 앱을 실행할 수 있다.
- 파일 탐색기에서 디렉토리를 탐색하고 파일을 열 수 있다.
- 작업 표시줄에 열린 창 목록을 표시한다.
- 활성화된 창과 비활성 창을 시각적으로 구분한다.
- 열린 창이 많을 경우 “더보기” UI를 구성한다.

## 📝 EPIC 6. 기본 어플리케이션 (Frontend 구현)

> 제어판, 메모장, 그림판, 계산기 등 시각적 UI 구현

- **제어판** UI – 폰트 크기, 배경색, 시간 설정 변경 가능
- **프로그램 관리자** UI – 설치된 앱 리스트, 실행/삭제 버튼 구성
- **파일 탐색기** UI – 파일 및 폴더 리스트, 클릭 시 동작
- **그림판** UI – 캔버스 드로잉, 색상 선택, 저장 버튼
- **계산기** UI – 사칙연산, M+, M-, MR, MC 버튼 지원
- **자유 앱** UI – 지뢰찾기 등 미니 게임 스타일 앱 구성

## 🧠 **Backend 백로그 (BE)**

> Node.js 기반 API 서버, 시스템 로직, 파일 시스템, 이벤트 동기화 구현

## 🧩 EPIC 1. 시스템 초기화 & 상태 관리

> OS의 부팅, 종료, 재시작, 로그 관리

- `/system/boot` API – 시스템 초기화 수행
- `/system/shutdown` API – 종료 및 리소스 해제
- `/system/restart` API – 재시작 시 상태 초기화
- `/system/status` API – 현재 버전, 상태, 실행 로그 반환
- `/system/logs` API – 전체 시스템 로그 조회

## 💾 EPIC 2. 파일 시스템

> 실제 파일 입출력 및 디렉토리 구조 관리

- `/syscall` 명령 처리: `ls`, `cd`, `pwd`, `mkdir`, `rm`, `cat`, `write`
- 텍스트 파일 생성 및 읽기 처리
- 디렉토리 탐색 결과를 JSON 형태로 반환
- 내부 파일 시스템 구조 유지 (`/root`, `/program`, `/example`)
- 파일 삭제 및 접근 제어 구현

## 🪟 EPIC 3. 윈도우 상태 및 이벤트 관리 API

> 윈도우 상태 저장, 이동, 이벤트 브로드캐스트

- `/windows/open` – 새 윈도우 생성 (id, title, x, y, w, h 반환)
- `/windows/move` – 윈도우 위치 업데이트
- `/windows/close` – 윈도우 닫기 및 리소스 해제
- `/system/window/{id}/state` – 창 위치, 크기 저장 및 복원
- `/system/gui/` – 마우스/키보드 이벤트 수집 및 처리
- 이벤트 브로드캐스트: 다중 클라이언트 상태 동기화

## 📝 EPIC 4. 어플리케이션 실행 및 관리

> Web OS 상에서 실행 가능한 프로그램 관리

- `/programs/list` – 설치된 프로그램 목록 반환
- `/programs/install` – 새 프로그램 등록
- `/programs/remove` – 프로그램 삭제
- `/programs/run` – 지정된 실행 파일(.app) 실행
- 프로그램 실행 시 내부 스크립트(`.ejs`) 파싱 및 결과 반환

## 📁 EPIC 5. 메모장 및 파일 저장

> 메모장, 그림판 등의 파일 I/O 백엔드 처리

- `/notepad/save` – 텍스트 파일 저장
- `/notepad/load` – 텍스트 파일 불러오기
- `/paint/save` – 이미지 데이터 저장 (base64 or blob)
- `/paint/load` – 저장된 이미지 불러오기

## 🧩 EPIC 6. 다중 사용자 & 세션 관리 (선택 구현)

> 여러 사용자 환경을 위한 격리된 컨테이너 지원

- 사용자별 세션 데이터 분리
- 각 사용자마다 독립된 파일 시스템 구조 유지
- 이벤트 브로드캐스트 시 사용자 컨텍스트 분리
- 도커 컨테이너 기반 격리 실행 지원
