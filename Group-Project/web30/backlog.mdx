## 백로그 (초안)

| 번호    | EPIC & STORY                                                           |
| :---- | :--------------------------------------------------------------------- |
| **1** | **[EPIC 1] 시스템 초기화 & 파일 시스템 **                                         |
| 1.1   | 사용자는 OS를 부팅, 재시작, 종료할 수 있다.                                            |
| 1.2   | 시스템은 부팅 시 기본 디렉토리 구조(/root, /program 등)를 초기화한다.                        |
| 1.3   | 사용자는 `ls`, `cd`, `pwd`, `mkdir`, `rm` 등의 명령어로 디렉토리를 탐색할 수 있다.          |
| 1.4   | 사용자는 `cat`, `write` 명령어로 텍스트 파일을 읽거나 생성할 수 있다.                         |
| 1.5   | 시스템은 현재 상태와 버전을 `/system/status` API를 통해 응답한다.                         |
| 1.6   | 백엔드는 모든 시스템 로그를 저장하며 `/system/logs`로 조회할 수 있다.                         |
| **2** | **[EPIC 2]** **터미널 (Terminal)**                                        |
| 2.1   | 사용자는 부팅 후 자동으로 터미널 창이 열린다.                                             |
| 2.2   | 사용자는 명령어를 입력창에 입력하고 결과를 출력창에서 확인할 수 있다.                                |
| 2.3   | 사용자는 `help`, `echo`, `date`, `uname`, `clear` 등 기본 명령어를 실행할 수 있다.      |
| 2.4   | 프론트는 입력된 명령어를 `/syscall` API로 백엔드에 전달하고 결과를 렌더링한다.                     |
| 2.5   | 명령 실행 중 오류가 발생하면 에러 메시지를 출력창에 표시한다.                                    |
| 2.6   | 터미널 상태는 전역 store로 관리되어 여러 터미널 간 일관성을 유지한다.                             |
| **3** | **[EPIC 3]** **윈도우 매니저 (Window Manager)**                              |
| 3.1   | 사용자는 여러 개의 윈도우를 동시에 띄울 수 있다.                                           |
| 3.2   | 사용자는 윈도우를 드래그로 이동시킬 수 있다.                                              |
| 3.3   | 클릭한 창은 z-index가 가장 위로 올라오며 활성화된다.                                      |
| 3.4   | 각 윈도우에는 제목 표시줄, 최소화, 전체화면, 닫기 버튼이 있다.                                  |
| 3.5   | 백엔드는 `/windows/open`, `/windows/close`, `/windows/move` API로 상태를 관리한다. |
| 3.6   | 윈도우 이동이나 크기 조정은 서버 응답 결과를 기반으로 반영된다.                                   |
| 3.7   | 시스템 재시작 시 열린 윈도우는 초기화된다.                                               |
| **4** | **[EPIC 4] UI 컴포넌트 & 전역 상태 관리**                                        |
| 4.1   | 시스템은 버튼, 입력창(1줄/다줄), 레이블 등의 공통 컴포넌트를 제공한다.                             |
| 4.2   | UI 요소들은 모든 앱(터미널, 메모장, 제어판 등)에서 재사용 가능해야 한다.                           |
| 4.3   | 프론트는 윈도우 매니저와 UI 상태를 전역 store로 관리한다.                                   |
| 4.4   | 애니메이션과 드래그앤드롭은 부드럽게 동작하도록 렌더링을 최적화한다.                                  |
| 4.5   | CSS는 자유롭게 구성하며, 필요 시 AI 기반 코드 생성을 허용한다.                                |
| **5** | **[EPIC 5]** **이벤트 처리 및 백엔드 연동**                                       |
| 5.1   | 프론트는 활성 윈도우의 마우스 이벤트(onMouseDown, onMove, onUp)를 백엔드로 전달한다.            |
| 5.2   | 프론트는 키보드 이벤트(keyDown, keyUp)를 감지하여 백엔드에 전달한다.                          |
| 5.3   | 백엔드는 `/system/gui/` API를 통해 이벤트를 수집하고 처리한다.                            |
| 5.4   | 서버는 이벤트 브로드캐스트를 통해 여러 클라이언트의 상태를 동기화한다.                                |
| 5.5   | `/system/window/{id}/state` 엔드포인트로 창 상태를 저장, 복원할 수 있다.                 |
| **6** | **[EPIC 6]** **파일 시스템 & 프로그램 관리**                                      |
| 6.1   | 사용자는 파일 관리자(탐색기)를 통해 폴더 및 파일을 탐색할 수 있다.                                |
| 6.2   | 사용자는 새 파일을 생성하고 내용을 수정·저장할 수 있다.                                       |
| 6.3   | 시스템은 프로그램 실행 파일(.app)을 파일 형태로 관리한다.                                    |
| 6.4   | 사용자는 파일 탐색기 또는 프로그램 관리자에서 앱을 실행할 수 있다.                                 |
| 6.5   | 프로그램 정보(아이콘, 레이아웃, 실행 코드)는 메타데이터로 저장된다.                                |
| **7** | **[EPIC 7]** **기본 어플리케이션 (Default Apps)**                              |
| 7.1   | 사용자는 **제어판**에서 폰트 크기, 배경색, 시간 등을 변경할 수 있다.                             |
| 7.2   | 사용자는 **메모장** 앱에서 텍스트를 작성, 저장, 불러오기 할 수 있다.                             |
| 7.3   | 사용자는 **그림판(Paint)** 앱에서 마우스로 그림을 그리고 저장할 수 있다.                         |
| 7.4   | 사용자는 **계산기(Calculator)** 앱에서 사칙연산 및 M+, M-, MR, MC 기능을 사용할 수 있다.       |
| 7.5   | 사용자는 **프로그램 관리자**에서 설치된 앱을 실행, 제거할 수 있다.                               |
| 7.6   | 자유 앱(지뢰찾기, 카드게임 등)을 추가로 구현할 수 있다.                                      |
| **8** | **[EPIC 8]** **바탕화면 & 작업표시줄 (Desktop Environment)**                    |
| 8.1   | 사용자는 바탕화면에 아이콘을 배치할 수 있다.                                              |
| 8.2   | 아이콘을 더블클릭하면 해당 애플리케이션을 실행할 수 있다.                                       |
| 8.3   | 작업표시줄에는 열린 윈도우 목록이 표시된다.                                               |
| 8.4   | 활성화된 창과 비활성화된 창은 구분되어 표시된다.                                            |
| 8.5   | 열린 창이 많을 경우 “더보기” 메뉴로 나머지를 확인할 수 있다.                                   |
