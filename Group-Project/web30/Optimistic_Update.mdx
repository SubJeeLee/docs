## \
**기술적 이야기에 앞서, ‘낙관적’이라는 말은 무엇을 뜻할까?**

‘낙관적(Optimistic)’이라는 단어는 단순히 긍정적인 태도나 기분 좋은 상태를 뜻하지 않습니다.

이 말의 본질은 **“결과가 잘 될 것이라 믿고 먼저 행동하는 태도”**입니다.

용어 그대로 _Optimistic_은 _Optimism_(낙관주의)에서 비롯되었는데, 이는

> “미래의 결과가 긍정적일 것이라 믿는 신념”
>
> “성공을 가정하고 행동하는 태도”
>
> 를 의미합니다.

소프트웨어 세계에서도 이 단어는 같은 철학을 공유합니다.

즉, **요청이 성공할 것이라고 가정하고, 그 결과를 먼저 반영하는 접근 방식**을 의미합니다!

이 사고방식이 바로 ‘**낙관적 업데이트(Optimistic Update)**’라는 개념으로 발전하게 되었습니다.

## **낙관적 업데이트란 무엇인가?** 

> 낙관적 업데이트는 **사용자가 어떤 액션을 했을 때, 서버 응답을 기다리지 않고 UI를 먼저 업데이트하는 기법**입니다.

보통의 요청 흐름은 이렇게 작동합니다:

```
사용자 액션 → 서버 요청 → 서버 응답 → UI 업데이트
```

하지만 낙관적 업데이트는 이렇게 동작합니다:

```
사용자 액션 → (성공할 것이라 믿고) UI 즉시 변경 → 서버 요청 → 실패 시 롤백
```

즉, **사용자가 느끼는 체감 반응 속도를 극대화**하기 위해 서버의 실제 결과를 기다리지 않고,

먼저 “성공했다고 가정한 상태”를 그려주는 것입니다.
