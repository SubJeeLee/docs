# 백준 입력

## 기본 템플릿

```javascript
const fs = require("fs");
const input = fs.readFileSync(0, "utf8").trim();
```

설명: 0은 표준입력(stdin) 파일 디스크립터다. Windows/맥/리눅스 모두 동작해서 가장 안전

```javascript
const fs = require("fs");
const lines = fs.readFileSync(0, "utf8").trim().split("\n");
const [N, M] = lines[0].split(" ").map(Number);
```

이 코드는 **첫 줄에 N M이 있고, 이후 줄에 추가 데이터가 있는 입력**에 맞다. 예시는 아래처럼:

`5 4 `\
`1 2 `\
`3 4 `\
`1 4 `\
`2 2 `

- 첫 줄 "5 4" → N=5, M=4
- 나머지 줄들은 lines[1]부터 별도로 처리하면

### 정규표현식을 활용한 전처리 (`split(/\s+/)`)

가장 강력하고 범용적인 입력 방법입니다. 공백, 탭, 줄바꿈이 어떻게 섞여 있든 **'의미 있는 데이터'**만 쏙쏙 골라 배열로 만들어줍니다.

```javascript
const fs = require("fs");
const input = fs.readFileSync(0, "utf8").trim().split(/\s+/);
// 예: "5 11\nbaekjoon\nonline judge" -> ["5", "11", "baekjoon", "online", "judge"]

const [N, M, ...words] = input;
```

#### 왜 정규표현식 `/\s+/`를 쓰나요?

- `split(" ")`**의 한계:** 공백 하나만 인식합니다. 줄바꿈(`\n`)이나 공백이 두 칸 이상 연속되면 빈 문자열(`""`)이 배열에 포함되는 버그가 발생할 수 있습니다.
- `\s`**(Whitespace):**  스페이스, 탭, 줄바꿈을 모두 포함하는 기호입니다.
- `+`**(One or more):**  공백이 여러 개 붙어 있어도 하나의 구분자로 취급하여 깔끔하게 나눠줍니다.

#### 언제 사용하나?

- 입력 데이터가 몇 줄인지 신경 쓰지 않고 **순서대로 값만 가져오고 싶을 때**
- 데이터 사이에 공백과 줄바꿈이 불규칙하게 섞여 있을 때 (예: 백준의 여러 단어 입력 문제)

# 배열

## 2차원 배열 생성

```javascript
const matrix = Array.from({ length: 100 }, () => Array(100).fill(0));
```

설명:

- `Array.from({ length: 100 })`로 행(100개)을 만들고,
- 각 행마다 `Array(100).fill(0)`으로 열(100개)을 채운다.

### **방향 배열 (상하좌우)**

```javascript
const dx = [1, -1, 0, 0];
const dy = [0, 0, 1, -1];

for (let k = 0; k < 4; k++) {
  const nx = x + dx[k];
  const ny = y + dy[k];
  if (nx < 0 || ny < 0 || nx >= R || ny >= C) continue;
  // matrix[nx][ny]
}
```

## 구조분해 할당 (Destructuring)

구조분해 할당은 배열/객체에서 값을 꺼내 변수에 바로 담는 문법이다.

### 배열 구조분해

```javascript
const arr = [10, 20, 30];
const [a, b] = arr;
console.log(a, b); // 10 20
```

구조분해 확장 예시

### **1) 첫 줄만 N, M이고 나머지는 전부 데이터 줄 (여러 줄 입력)**

```javascript
const fs = require("fs");
const [first, ...rest] = fs
  .readFileSync("example.txt")
  .toString()
  .trim()
  .split("\n")
  .map(v => v.split(" ").map(Number));

const [N, M] = first;
const data = rest; // 나머지 모든 줄 (2차원 배열)
```

### **2) 첫 줄 N, M + 나머지는 한 줄씩 쌍 (a, b)**

```javascript
const fs = require("fs");
const [first, ...pairs] = fs
  .readFileSync("example.txt")
  .toString()
  .trim()
  .split("\n")
  .map(v => v.split(" ").map(Number));

const [N, M] = first;
for (const [a, b] of pairs) {
  // a, b 사용
}
```

## 배열 원하는 만큼 자르기 (`slice`)

`slice()`는 배열의 일부분을 복사하여 새로운 배열을 만듭니다. **원본 배열을 건드리지 않는다**는 점이 최대 장점입니다.

```javascript
// 기본 문법: array.slice(start, end)
const words = ["a", "b", "c", "d", "e"];

const firstTwo = words.slice(0, 2); // 인덱스 0부터 2 "직전"까지 -> ["a", "b"]
const fromThird = words.slice(2);   // 인덱스 2부터 "끝"까지 -> ["c", "d", "e"]
```

- **start**: 시작 인덱스 (포함)
- **end**: 종료 인덱스 (**미포함**). 생략하면 배열 끝까지 가져옵니다.
- **특징**: 원본은 그대로 두고 **복사본**만 만들기 때문에 부수 효과(Side Effect)가 없어 안전합니다.

# 정렬 (sort)

자바스크립트의 `sort()`는 콜백 함수를 통해 정렬 우선순위를 정할 수 있습니다.

```javascript
const arr = words.sort((a, b) => {
  // 1순위: 길이순 (짧은 것이 위로)
  if (a.length !== b.length) return a.length - b.length;

  // 2순위: 사전순 (길이가 같을 때)
  if (a < b) return -1; // a가 b보다 작으면(사전 앞쪽이면) 음수 반환 -> 그대로 유지
  if (a > b) return 1;  // a가 b보다 크면 양수 반환 -> 위치 변경
});
```

- **반환값의 의미:** \* **음수:** `a`를 `b`보다 앞에 둠
  - **양수:** `b`를 `a`보다 앞에 둠
  - **0:** 순서 유지

# 중복 제거 (`Set` 자료구조)

`Set`은 중복된 값을 허용하지 않는 특수한 객체입니다.

```javascript
[...new Set(arr)]
```

- `new Set(arr)`: 배열 `arr`에서 중복된 단어들을 자동으로 날려버립니다.
- `[...]`**(Spread 연산자)** : Set 객체를 다시 일반 배열로 펼쳐줍니다. 그래야 이후에 정렬된 결과물로 사용할 수 있습니다.

## 집합(Set)과 데이터 존재 확인 (`has`)

중복 제거용으로만 알기 쉬운 `Set`은 사실 **'검색 속도'** 때문에 코테에서 필수입니다.

```javascript
const sSet = new Set(["apple", "banana", "orange"]);

// 특정 데이터가 있는지 확인
console.log(sSet.has("apple"));  // true
console.log(sSet.has("grape"));  // false
```

#### ★ 왜 `Array.includes()` 대신 `Set.has()`를 쓰나요?

- `Array.includes()`: 배열을 처음부터 끝까지 다 뒤져야 합니다. (시간 복잡도: **$O(N)$**)
  - 데이터가 10만 개면 최대 10만 번 연산합니다.
- `Set.has()`: 해시 테이블 구조를 사용해 즉시 찾아냅니다. (시간 복잡도: **$O(1)$**)
  - 데이터가 10만 개든 100만 개든 **단 한 번**에 찾습니다.

> **코테 팁:** "어떤 값이 집합에 포함되어 있는가?"를 묻는 문제(예: 백준 14425번)에서 배열을 그대로 쓰면 **시간 초과**가 날 확률이 높습니다. 반드시 `Set`으로 변환한 뒤 `has()`를 사용하세요.

# 출력 TIP

## 출력 최적화 (`join`) 사용

반복문으로 하나씩 출력(`console.log`)하는 것보다, 하나의 큰 문자열로 합쳐서 한 번에 출력하는 것이 훨씬 빠릅니다.

```javascript
console.log(arr.join("\n"));
```

`join("\n")`: 배열의 각 요소를 줄바꿈 문자(`\n`)로 연결하여 하나의 문자열로 만듭니다.
