## 백준 입력

### 기본 템플릿

```javascript
const fs = require("fs");
const input = fs.readFileSync(0, "utf8").trim();
```

설명: 0은 표준입력(stdin) 파일 디스크립터다. Windows/맥/리눅스 모두 동작해서 가장 안전

```javascript
const fs = require("fs");
const lines = fs.readFileSync(0, "utf8").trim().split("\n");
const [N, M] = lines[0].split(" ").map(Number);
```

이 코드는 **첫 줄에 N M이 있고, 이후 줄에 추가 데이터가 있는 입력**에 맞다. 예시는 아래처럼:

`5 4 `\
`1 2 `\
`3 4 `\
`1 4 `\
`2 2 `

- 첫 줄 "5 4" → N=5, M=4
- 나머지 줄들은 lines[1]부터 별도로 처리하면 됨

## 배열

### 2차원 배열 생성

```javascript
const matrix = Array.from({ length: 100 }, () => Array(100).fill(0));
```

설명:

- `Array.from({ length: 100 })`로 행(100개)을 만들고,

- 각 행마다 `Array(100).fill(0)`으로 열(100개)을 채운다.\
\
**방향 배열 (상하좌우)**

```javascript
const dx = [1, -1, 0, 0];
const dy = [0, 0, 1, -1];

for (let k = 0; k < 4; k++) {
  const nx = x + dx[k];
  const ny = y + dy[k];
  if (nx < 0 || ny < 0 || nx >= R || ny >= C) continue;
  // matrix[nx][ny]
}
```

### 구조분해 할당 (Destructuring)

구조분해 할당은 배열/객체에서 값을 꺼내 변수에 바로 담는 문법이다.

### 배열 구조분해

```javascript
const arr = [10, 20, 30];
const [a, b] = arr;
console.log(a, b); // 10 20
```

구조분해 확장 예시

**1) 첫 줄만 N, M이고 나머지는 전부 데이터 줄 (여러 줄 입력)**

```javascript
const fs = require("fs");
const [first, ...rest] = fs
  .readFileSync("example.txt")
  .toString()
  .trim()
  .split("\n")
  .map(v => v.split(" ").map(Number));

const [N, M] = first;
const data = rest; // 나머지 모든 줄 (2차원 배열)
```

**2) 첫 줄 N, M + 나머지는 한 줄씩 쌍 (a, b)**

```javascript
const fs = require("fs");
const [first, ...pairs] = fs
  .readFileSync("example.txt")
  .toString()
  .trim()
  .split("\n")
  .map(v => v.split(" ").map(Number));

const [N, M] = first;
for (const [a, b] of pairs) {
  // a, b 사용
}
```
